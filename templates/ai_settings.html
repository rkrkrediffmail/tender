Setup Instructions
Claude (Anthropic)
  1. Visit Anthropic Console
  2. Create an account and get API key
  3. Set environment variable: ANTHROPIC_API_KEY=your_key
  4. Restart the application
OpenAI GPT
  1. Visit OpenAI Platform
  2. Create an account and get API key
  3. Set environment variable: OPENAI_API_KEY=your_key
  4. Restart the application
Tip: You can configure both providers and the system will automatically fallback if the primary provider fails.
Model Availability: GPT-5 and GPT-4.1 models may not be available yet. The system will show an error if you select an unavailable model. Current production models are Claude Sonnet 4 and GPT-4 Turbo.
